Part 1: Difference-in-Differences (DiD)

In this section, we will learn how to estimate Difference-in-Differences (DiD) models using the 2x2 and Two-Way Fixed Effects (TWFE) approaches.

DiD is one of the most widely used quasi-experimental designs in applied economics and policy evaluation, precisely because it doesn’t require a true randomized experiment, it only requires a treated group, a comparison group, and data both before and after treatment. The logic behind DID is that if the event never happens, the differences between treatment and control groups should stay the same overtime. Today we’ll build our intuition for when that’s enough, and when it isn’t.

Simulation

Assume we have two time periods (\(T = 0, 1\)) and two groups (\(G = 0, 1\)). We are interested in the effect of a treatment \(Z\), which switches on in time period \(T=1\), on an outcome \(Y\). We will assume a panel data setting in which units are observed three times (\(T = -1, 0, 1\)).

Given this setup, we can now simulate a dataset with 1000 units (3000 observations). We will first simulate the potential outcomes \(Y0\) and \(Y1\) as a function of \(T\), \(Z\), and an error term.

N <- 1000
ATE <- 2

set.seed(123)
data <- tibble(
  # First, create a unit id such that each observation is observed three times:
  id = sort(rep(1:N, 3)),
  # Now, generate our time variable such that each observation is observed in all three periods:
  t = rep(c(-1, 0, 1), N),
  # Next, generate our group variable such that each observation is in one of two groups:
  G = c(replicate(N, rep(sample(c(0, 1), 1), 3))),
  Z = ifelse(t == 1, G, 0),
  # Assign our error term as an idiosyncratic term:
  U = rnorm(N * 3),
  # Generate Y0 as a function of U, G, and t:
  Y0 = 1 + 0.5 * t + 1 * G + 2 * U,
  # Generate Y1 as a function of Y0, the ATE, and t:
  Y1 = Y0 + rnorm(N, ATE, 0.25),
  # Realize Y from PO and Z:
  Y = Y1 * Z + Y0 * (1 - Z)
)

# Let's check our ATT in post-period (given our DGP, = ATE):
mean(data$Y1[data$Z == 1]) - mean(data$Y0[data$Z == 1])

Part 2: Regression Discontinuity (RD)

RD designs exploit situations where treatment is assigned based on whether some running variable crosses a cutoff — a test score, an age threshold, a vote margin. The core idea: units just above and just below the cutoff should be nearly identical in everything except treatment, so comparing them close to the cutoff approximates a randomized comparison, even though nobody randomized anything.

Simulation

N <- 1000
LATE <- 2
c <- 5 # we won't use this just yet

data <- tibble(
  # First, assign X and U:
  X = runif(N, 0, 10),
  U = rnorm(N),
  Q = rnorm(N),
  # Next, assign Y0:
  Y0 = 1 + 0.5 * X - 0.05 * (X^2) + 0.025 * (X^3) - 0.0025 * (X^4) + 0.5 * U,
  Y1 = Y0 + rnorm(N, LATE, 0.25) - 0.5 * X + 0.1 * (X^2)
)

Diagnostic Plots

One of the key assumptions of RD designs is continuity of the potential outcomes at the cutpoint. This assumption is violated if individuals sort (self-select) into treatment or control. However, if this happens, it can leave traces in the data that we can detect. Namely, we get a jump in the density of the running variable at the cutpoint. We can test for this using the rddensity() and rdplotdensity() functions from the {rddensity} package:

density_test <- rddensity::rddensity(data$X, c = 5)
summary(density_test)

rddensity::rdplotdensity(density_test, data$X)$Estplot

Answer

The rdrobust function estimates a smaller LATE than the regression model (7.4 vs. 9.4). There are several reasons for this:

  • The rdrobust function uses a local linear regression, which means that only observations within a certain bandwidth around the cutpoint are used to estimate the LATE. The regression model, on the other hand, uses all observations in the sample.

  • The rdrobust function used a polynomial of order 1 to estimate the LATE, while the regression model used a polynomial of order 4.

  • The rdrobust function gives more weight to observations closer to the cutpoint, while the regression model gives equal weight to all observations.
